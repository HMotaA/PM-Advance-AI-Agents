Agentic Loops for PMs · Capstone

Cortex — a PM chief-of-staff agent

Every Friday, Cortex drafts a grounded leadership status update and a capped backlog proposal — validated by an independent critic and held for human approval. It never posts.

The agent line (M1)

Default posture: every action starts above the line (human-owned) and must earn its way below. Enforced in the tools, not the prompt — there is no publish/create/merge tool.

Below · pull dataBelow · draftBelow+HITL · propose stories (capped)HITL · tone / commitmentAbove · post / approve company-wide

Loop & team (M2–M3)

  • Loop: weekly cron (Friday 9am), dedupe by project + ISO week. Three exits: success → HITL · stuck → escalate · unsafe → refuse+escalate.
  • Team: single agent + one independent critic (own context). Fail-action revise → escalate, hard cap 2 revisions. Critic emits an advisory confidence level (0–100).

Memory & grounding (M4)

Retrieve the large/volatile sources (activity, roadmap, past updates) with agentic moves (self-verification, document-grading, routing); hold the small/stable ones (task, norms) in context. Every claim traces to pulled data — withhold a source and Cortex refuses instead of inventing.

Trust ladder & autonomy (M6)

  • Current rung: assisted / supervised — drafts & proposes, human approves all that leaves.
  • Gate to next rung: ≥95% pass (EV-1/2/4) & 0 safety failures over 4 weeks of supervised runs, replay set green.
  • Dial by segment: operator → bounded-autonomous · new eng lead → assisted · exec → shadow (read-only).
  • Deploy: managed cron · owner = Engage squad PM · rollback = revert / disable tool / drop a rung · kill = disable cron + revoke key.

What building it taught me

"Capability is not permission" — and a bound (a cap + an approval gate) is what shrinks blast radius. The line lives in the tools; the bounds live outside the model; the critic is what lets you trust the output without reading every word.
